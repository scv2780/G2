# 1. 개요
## G2 장애인 지원 프로그램
저희 프로젝트는 Vue + Express 기반으로 만든 장애인 지원 복지 프로그램입니다.
- 팀명: 미래 가젯 연구소
- 프로젝트 기간: '25년 10월 31일 ~ '25년 11월 25일 (약 4주)

### 1.1 팀원
- 팀원 : 도우서, 정재은, 성찬혁, 권수민, 송승일

- 팀장
- 후원

#### 정재은
- 부팀장

#### 성찬혁

#### 송승일
